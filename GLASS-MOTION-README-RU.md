# MGE OS — экспериментальный патч стекла и переходов

Это дополнение к текущему app/src/main/assets/index.html, НЕ полный исходный проект и НЕ APK. Подготовительный патч согласия/профиля из предыдущего сообщения отдельно; этот архив его не заменяет. Репозиторий не изменён.

Распаковать поверх корня MGE-OS и выполнить python3 tools/install_glass_addon.py. Скрипт проверяет якоря, делает резервную копию HTML, добавляет скрипт без замены существующих обработчиков и не меняет старый ключ localStorage. Затем штатная сборка APK. Повторная установка блокируется. Для отмены восстановить app/src/main/assets/index.before-glass.html как index.html. Перед коммитом исключить резервную копию из APK или вынести её за assets.

Сделано: полупрозрачные панели дока/шторок и найденных карточек, светлая кромка, блик, тень; кэш уменьшенного размытого изображения обоев; позиционирование подложки по панели; live backdrop blur максимум двух панелей в High, одной в Balanced, без него в Economy. Тема стекла адаптируется к яркости обоев; ручное переключение. Есть локальные настройки прозрачности, качества и переходов. Анимации страниц и панелей изменяются через CSS, существующая перетаскиваемая страница сохраняет transition:none. В фоне обновления прекращаются. Точки обновления фона пересчитываются по событиям, не постоянным циклом в покое.

Ограничения: live blur содержимого выполняет WebView; это НЕ кэш снимков всего контента. Пресеты ограничивают число таких поверхностей, но точное время GPU требует профилирования. Кэш растровый, при несовпадении фоновых transform возможны погрешности позиционирования. При ошибке декодирования остаётся tint без кэша. Автокачество использует профиль только если установлен первый патч, иначе Balanced. Иконки OEM, расширенная кастомизация и morph содержимого окна чужого приложения НЕ реализованы. Переключатель ColorOS относится только к переходам UI лаунчера и не выдаёт себя за системную интеграцию.

Проверки в подготовке: node --check, синтаксис Python, тест установки/повторной установки на HTML-фикстуре. На исходном WebView, Pixel и Android-компиляции не проверялось. Не обещаем 60/120 fps без измерений. Некоторые папки/карточки могут требовать корректировки CSS-селекторов после просмотра полного исходного HTML.
