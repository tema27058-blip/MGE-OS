# MGE OS — экспериментальный Android-лаунчер 0.1

Это исходный проект, НЕ готовый APK. Код не был собран или протестирован на устройстве в среде автора. Сборка требует внешнего Android SDK/Gradle. Возможны ошибки и различия в плавности на Pixel.

## Что реализовано
- HOME Activity, запрос роли основного домашнего приложения через системное окно.
- Локальный WebView UI, без INTERNET-разрешения, без рекламы и внешних JS-библиотек.
- Настоящие запускаемые Activity основного профиля, обновление при установке/удалении.
- Запуск через ActivityOptions.makeScaleUpAnimation из координат иконки.
- Чёрно-красные плитки, монохромные оригинальные значки (не авторская перерисовка всех брендов).
- Две страницы, свайп, каскад иконок, вращающееся свечение, квадратные обои, док.
- Поиск, одна папка, выбор обоев, сохранение оформления, изменение порядка.
- Долгое нажатие: добавить/убрать на рабочем столе, в доке и папке, сведения о приложении.

## Как собрать с телефона на GitHub
1. Создай репозиторий (лучше приватный) с основной веткой main.
2. Загрузи СОДЕРЖИМОЕ папки MGE-OS из ZIP в корень репозитория. Один ZIP загружать недостаточно.
3. Важно: .github/workflows/build.yml тоже должен попасть в репозиторий. Если мобильная загрузка скрывает .github, создай через Add file → Create new file путь .github/workflows/build.yml и вставь содержимое файла.
4. Открой Actions → Build MGE APK → Run workflow. Workflow также запускается при push в main/master.
5. Дождись зелёной сборки. Открой запуск → Artifacts → MGE-OS-debug-APK. Скачай и распакуй ZIP; внутри app-debug.apk.
6. Разреши установку для приложения, из которого открываешь APK, и установи. Открой MGE OS → шестерёнка → Сделать основным лаунчером → выбери MGE OS в Android.
При ошибке сборки сохрани лог красного шага. Доступность и лимиты GitHub Actions зависят от аккаунта/репозитория.

## Важное про подпись обновлений
По умолчанию каждый чистый runner генерирует новый debug-ключ. APK разных сборок без постоянного ключа НЕ гарантированно обновляют друг друга: Android отклонит несовпадающую подпись. Удаление старого приложения сотрёт его настройки.
Для стабильных тестовых обновлений сохрани свой debug.keystore в секрете репозитория MGE_DEBUG_KEYSTORE_BASE64 (base64 без переносов). Workflow использует его из ~/.android/debug.keystore.
Создать совместимый debug-ключ на компьютере с JDK:
keytool -genkeypair -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
Никогда не публикуй ключ в репозитории. Для публикации в магазине нужен отдельный release-процесс; этот workflow собирает только debug APK.

## Ограничения
Нет нативных Android-виджетов, рабочих/закрытых профилей, сменных icon pack, панели недавних приложений Quickstep и редактирования нескольких папок. Исходные обои 200×200: встроены без обещания увеличенной детализации. Выбранные обои масштабируются до 1000×1000 и сохраняются локально.
Системная анимация старта — запрос Android, а не гарантия Pixel Launcher morph. Свайп домой, закрытие чужих приложений и недавние приложения остаются под управлением системы; без системной интеграции нельзя обещать идентичные Pixel переходы.
WebView bridge принимает только выбранные запускаемые компоненты; удалённая навигация и загрузка ресурсов блокируются. Не добавляй загрузку внешних страниц в этот WebView.

## Проверка на Pixel перед постоянным использованием
- Установка и выбор Home, повторное нажатие Home, перезапуск телефона.
- Поиск и запуск разных приложений, свайп домой, клавиатура, длинные названия.
- Установка/удаление приложения и обновление списка.
- Долгое нажатие, добавление и удаление из дока/папки, сохранение после перезапуска.
- Выбор новых обоев и сброс.
- Кнопка Назад и системные отступы с жестовой навигацией.
- Снижение движения, доступность и производительность.

## Как вернуть Pixel Launcher
Настройки Android → Приложения → Приложения по умолчанию → Главный экран → Pixel Launcher. Только после переключения удаляй тестовый лаунчер.

## Компьютер
Открой корень проекта в Android Studio, установи SDK 35, Gradle 8.11.1 и JDK 17. Wrapper намеренно не включён (нет gradle-wrapper.jar). Для CLI с установленным Gradle: gradle :app:assembleDebug.
