# MGE OS 0.3 — оптимизация

Это полный исходный проект, не APK. Основа — предоставленный пользователем MGE-OS-main.zip (0.1), с восстановленными функциями 0.2 и переработанным UI 0.3. Это НЕ побайтовая правка прежнего сгенерированного ZIP 0.2, который недоступен в текущей среде.

## Обновление GitHub
Распакуй архив. Из папки MGE-OS перетащи ТОЛЬКО папку app в корень своего репозитория через Code → Add file → Upload files. Не открывай app перед загрузкой. Нужны пути app/build.gradle и app/src/main/..., без app/app или MGE-OS/app.
Сохрани Commit changes в main. Твой успешный .github/workflows/build.yml менять не нужно. В этом архиве исправление packages: platform-tools сохранено.
Actions → свежая сборка → Summary → Artifacts → MGE-OS-debug-APK. Скачай, распакуй и установи app-debug.apk.

## Подпись
Старый workflow не сохраняет автоматически debug-keystore между чистыми runner. Если постоянный ключ не настроен, новая подпись может отличаться. Сначала попробуй обычную установку поверх старой. Если сообщение о несовпадающей подписи/конфликте пакета — переключи Home на Pixel Launcher, удали прежний MGE OS, затем установи новый (настройки сотрутся). Не отключай Play Protect. Для стабильных обновлений используй секрет MGE_DEBUG_KEYSTORE_BASE64, описанный в README-RU.md.

## Что оптимизировано
- Удалены все CSS filter и backdrop-filter, включая размытие при каскаде иконок.
- Нет canvas-отрисовки фона каждый кадр: градиентное освещение заранее растрировано и встроено, движение — transform/opacity.
- Страницы переключаются за 240 мс по умолчанию; кнопки реагируют за 100 мс. Каскад ограничен первыми 8 ступенями по 18 мс, чтобы крупная сетка не появлялась секунду.
- Нет синхронного принудительного layout для перезапуска эффектов.
- Список приложений не пересоздаётся и не отправляется из Java при каждом onResume.
- Во время свайпа декоративные анимации приостанавливаются, движения сгруппированы через requestAnimationFrame.
- Скрытая страница обоев не анимируется. В фоне эффекты останавливаются.
- Поиск отложен на 60 мс и не пересоздаёт одинаковый список повторно.
- Цветные и красно-градиентные версии значков подготовлены один раз в фоновом Java-потоке, CSS не перекрашивает изображения в ходе анимаций.
- Искры и постоянное вращение больших размытых слоёв сознательно убраны как лишняя нагрузка.

## Внешний вид
Сами значки окрашиваются красным градиентом с сохранением структуры исходного изображения, не только плитка. Переключатель Красный градиент значков позволяет вернуть оригиналы. Это автоматическая окраска, не индивидуально нарисованные значки для каждого бренда. В текущей реализации лаунчер по-прежнему использует WebView.
Убраны стандартная tap-highlight, подсветка overscroll, текстовое выделение вне ввода и контекстное меню. Фокус клавиатуры сохранён и красный. Папки/действия создаются собственными панелями; некоторые элементы системного выбора (обои, роль Home, селекты WebView) по-прежнему могут выглядеть системно.

## Анимации запуска и возвращения
Перед стартом нажатая иконка сжимается. Android получает ActivityOptions.makeScaleUpAnimation из её координат. После возвращения из запущенного приложения рабочий стол появляется коротким эффектом 170 мс БЕЗ перестройки всех страниц.
Это НЕ управление окном чужого приложения при закрытии. Морфинг закрытия как у системного Pixel Launcher/Quickstep и эффекты VoidLauncher не гарантируются. Собственная анимация возвращения не заменяет системную.

## Сохранённые функции
Автозаполнение всех запускаемых приложений, страницы, док, одна папка, долгие нажатия/действия, поиск, выбор основного лаунчера, своя статус-панель с батареей и типом подключения, безопасная зона камеры, настройки сетки/строк/отступов/подписей/дока/обоев/анимаций/папки/старта. Настройки хранятся под прежним ключом mge.native.v1. Первый запуск 0.3 дополняет список приложений один раз, затем сохраняет ручные удаления.

## Проверки
Синтаксис JS проверен node --check. XML разобран парсером. Handler загрузки приложений проверен Node-тестами: пустой первый ответ, 65 приложений, сохранение ручных удалений, новые установки, переключатель автодобавления, очистка удалённых приложений.
Java/Android здесь НЕ компилировались и Pixel не профилировался. Поэтому нельзя гарантировать FPS или отсутствие ошибок конкретного WebView. Сначала проверь запуск, свайпы, доступность настроек и несколько приложений, затем назначай Home.
Для диагностики сообщи: версия Android/WebView, где остаются задержки (свайп/поиск/обои/возврат), включено ли энергосбережение. Не снимай ограничения системы и не включай принудительно GPU-настройки разработчика ради этого приложения.
